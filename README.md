## 🛠️ About

The **gimp-kindle-templates** is a plugin for GIMP 3.0 that helps you create Kindle templates. It focuses on specific image types and provides the ideal sizes for KDP (Kindle Direct Publishing). This tool ensures that your images fit within the safe area and are organized in a way that makes sense for publishing.
