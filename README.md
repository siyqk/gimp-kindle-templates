# GIMP Kindle Templates

Plug-in para GIMP 3.0 que cria templates Kindle com SAFE-AREA automática,
guias e estrutura limpa, seguindo Clean Code e a API oficial libgimp 3.0.

## Recursos
- Template 1600x900
- SAFE-AREA automática (5%)
- Camada protegida
- Guias automáticas
- Código compatível com GIMP 3.0 (GI)

## Instalação
```bash
cp src/kindle_templates/kindle_templates.py \
   ~/.config/GIMP/3.0/plug-ins/kindle_templates/
chmod +x ~/.config/GIMP/3.0/plug-ins/kindle_templates/kindle_templates.py
